## Font Theme (SAP 2023)

The SAP template uses the "72 Brand" font family:

| Usage | Font Name | Weight |
|-------|-----------|--------|
| Major Font (Headings) | 72 Brand Medium | Medium (500) |
| Minor Font (Body) | 72 Brand | Regular (400) |

**Note:** The 72 Brand font family must be installed on your system for proper rendering. If not available, PowerPoint will substitute with a similar sans-serif font.

## Color Usage Guidelines

### Primary Brand Colors

- **SAP Blue (#1B90FF)**: Use as the primary brand identifier, headers, and key UI elements
- **White (#FFFFFF)**: Primary background color
- **Black (#000000)**: Primary text color

### Accent Colors by Purpose

| Purpose | Recommended Color | Hex |
|---------|-------------------|-----|
| Call to Action | Mango | `#E76500` |
| Success/Positive | Green | `#36A41D` |
| Warning | Mango | `#E76500` |
| Error/Critical | Red | `#EE3939` |
| Information | SAP Blue | `#1B90FF` |
| Links | Link Blue | `#0070F2` |

### Data Visualization

For charts and graphs, use this sequence:

2. Mango (`#E76500`)

4. Green (`#36A41D`)

## Programmatic Color Usage

### Python-pptx Example

```python
from pptx.dml.color import RgbColor
from pptx.util import Pt

# Define SAP colors
SAP_COLORS = {
    "sap_blue": RgbColor(0x1B, 0x90, 0xFF),
    "mango": RgbColor(0xE7, 0x65, 0x00),
    "teal": RgbColor(0x04, 0x9F, 0x9A),
    "green": RgbColor(0x36, 0xA4, 0x1D),
    "raspberry": RgbColor(0xFA, 0x4F, 0x96),
    "pink": RgbColor(0xF3, 0x1D, 0xED),
    "indigo": RgbColor(0x78, 0x58, 0xFF),
    "black": RgbColor(0x00, 0x00, 0x00),
    "white": RgbColor(0xFF, 0xFF, 0xFF),
}

# Apply color to text
run.font.color.rgb = SAP_COLORS["sap_blue"]

# Apply color to shape fill
shape.fill.solid()
shape.fill.fore_color.rgb = SAP_COLORS["mango"]
```

### Hex to RGB Conversion

```python
def hex_to_rgb(hex_color):
    """Convert hex color to RGB tuple."""
    hex_color = hex_color.lstrip('#')
    return tuple(int(hex_color[i:i+2], 16) for i in (0, 2, 4))

# Example
rgb = hex_to_rgb("#1B90FF")  # Returns (27, 144, 255)
```

## Accessibility Considerations

When using colors, ensure sufficient contrast:

| Background | Recommended Text Color | Contrast Ratio |
|------------|------------------------|----------------|
| White | Black | 21:1 |
| White | SAP Blue | 4.5:1 |
| SAP Blue | White | 4.5:1 |
| Mango | Black | 4.5:1 |

**WCAG Guidelines:**
- Normal text: minimum 4.5:1 contrast ratio
- Large text (18pt+): minimum 3:1 contrast ratio
